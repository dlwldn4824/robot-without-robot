# 눈 감고 주차하기

2026 AWS Community Day Seoul 가짜연구소 부스용 데모. 한 사람당 60초면 끝납니다.

**[▶ 브라우저에서 열기](https://dlwldn4824.github.io/robot-without-robot/booth/)**

## 무엇을 보여주나

방향키로 로봇을 몰아 주차 칸에 넣습니다. 화면에 보이는 로봇은 실제 위치가 아니라 **로봇이 믿는 위치**입니다.
달릴수록 파란 원이 커지고, 그게 로봇이 자기 위치를 모르게 되는 정도입니다.

| 모드 | 무슨 일이 일어나나 |
| --- | --- |
| 보정 없음 | 원이 계속 커집니다. 바퀴가 돈 횟수만 세기 때문에 미끄러진 만큼은 셀 방법이 없습니다 |
| SLAM 보정 | 앞쪽 표식이 보일 때마다 원이 줄어듭니다. 돌아서서 안 보이면 다시 커집니다 |
| 펌웨어 자율 | 아무도 안 할 때 `firmware.c` 가 혼자 IR·비컨을 보고 주차합니다 |

끝나면 주행을 되감아 보여 줍니다. 믿은 경로와 실제 경로가 어디서부터 벌어졌는지 그때 보입니다.

## 펌웨어

바퀴 명령과 센서 변환은 설명용 코드가 아니라 [`../w6-firmware-c/firmware.c`](../w6-firmware-c/firmware.c)
를 wasm32로 컴파일한 것입니다. 같은 파일이 보드용 `.elf`, MuJoCo용 `.dylib`, 브라우저용 `.wasm`
세 갈래로 나갑니다. 정수 연산만 쓰고 malloc 이 없어서 4.3 KB 입니다.

쓰는 함수는 `fw_i_tick`, `fw_i_out_l/r`, `fw_i_state`, `fw_mm_to_adc`, `fw_beacon`,
`fw_v_mm_s`, `fw_w_mdeg_s` 입니다.

## 파일

| 파일 | 용도 |
| --- | --- |
| `index.html` | **부스에서 쓰는 것.** 더블클릭하면 열립니다. 인터넷도 서버도 필요 없습니다 |
| `parking.html` | 원본. wasm 이 base64 로 들어 있습니다 |
| `build-offline.py` | `parking.html` → `index.html` |
| `firmware.wasm` | 빌드 산출물 (참고용, 이미 페이지 안에 들어 있습니다) |

```bash
python3 build-offline.py      # parking.html 을 고친 뒤
```

## 부스에서

- 노트북 절전을 끄고 전체화면(`⌃⌘F`)으로 띄웁니다
- 15초 동안 입력이 없으면 알아서 처음 화면으로 돌아가고, 펌웨어가 혼자 돌기 시작합니다
- 점수는 브라우저에만 쌓입니다. 서버로 아무것도 보내지 않습니다
